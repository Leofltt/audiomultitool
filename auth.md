# auth.md

Welcome to AudioMultiTool. This document describes the authentication flow for AI agents.

## Agent Audience
All AI agents looking to access the Web Audio suite programmatically or register capabilities.

## Registration API
Agents can register at: `https://audiomultitool.com/agent/register`

### Details
- **Supported Identity Types**: `anonymous`
- **Supported Credential Types**: `api_key`
- **Claim URL**: `https://audiomultitool.com/agent/claim`
