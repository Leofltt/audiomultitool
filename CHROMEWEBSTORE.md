# Chrome Web Store Metadata: AudioMultiTool Extension

This file tracks the Developer Dashboard listing details and submission metadata for the AudioMultiTool Chrome Extension.

---

## 1. Store Listing Details

*   **Extension Name**: AudioMultiTool - Free Online Audio Utilities
*   **Summary (160 chars max)**: Fast, 100% client-side web audio utilities: precision online metronome, chromatic tuner, easy voice recorder, DB decibel meter, and audio converter.
*   **Detailed Description**:
    AudioMultiTool is a high-performance, privacy-first suite of web audio tools that runs 100% inside your browser. No file uploads, no account signups, absolute privacy.

    Launch any of the tools directly from your browser:
    - **Online Metronome**: High-precision, drift-free click generator with custom subdivisions, bpm tap tempo calculator, and network sync.
    - **Easy Voice Recorder**: Capture microphone or system audio loopbacks locally without file size limitations.
    - **Online Audio Converter**: Convert MP3, WAV, OGG, M4A, FLAC, and WebM files locally in seconds.
    - **Chromatic Tuner**: Fast pitch detector using auto-correlation algorithms for guitars, violins, ukuleles, and more.
    - **Tone & Noise Generator**: Generate pure frequencies, sweeps, and white/pink/brownian noise for testing or focus.

    All processing happens locally on your computer. Your audio files and recording feeds are never uploaded to any remote server.
*   **Category**: Developer Tools / Productivity
*   **Official Homepage URL**: https://audiomultitool.com
*   **Privacy Policy URL**: https://audiomultitool.com/privacy.html

The extension requests zero special permissions. It acts as a lightweight launcher to open the web application.

*   **Permissions**: `[]`
*   **Host Permissions**: `[]`

## 3. Privacy & Data Use Disclosure

*   **Data Collection**: This extension does not collect, store, or transmit any user data. All operations are local link shortcuts.
*   **Single-Purpose Description**: The sole purpose of this extension is to provide users with a quick-access toolbar launcher for the client-side AudioMultiTool web applications.
