# Client-Side Audio Converter Skill

Exposes capabilities to decode and convert audio files locally without remote server uploads.

## Parameters
- **Decoding**: Browser-native file decoding to PCM data.
- **Formats**: Transcodes audio to WAV (uncompressed byte stream writer) or MP3 (LAME chunk encoder).
- **Privacy**: 100% client-side operation keeping user audio private.
