# Speaker Frequency Sweep Skill

Exposes capabilities to generate sweep pitches to test acoustic boundaries and speaker crossover ranges.

## Parameters
- **Start Frequency**: Starting register frequency in Hz.
- **End Frequency**: Ending register frequency in Hz.
- **Duration**: Progression runtime duration in seconds.
- **Curve type**: Logarithmic vs linear frequency sweep curve scaling.
