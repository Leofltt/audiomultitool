# Tone Generator Skill

Exposes capabilities to procedurally generate pure audio frequencies using browser oscillators.

## Parameters
- **Waveform**: Sine, Square, Sawtooth, Triangle.
- **Frequency**: Custom tone pitch in Hertz (range: 20 Hz - 20,000 Hz).
- **Control**: Logarithmic slider controls for precise registers tuning.
